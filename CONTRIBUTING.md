# Contributing to GitHub Profile Guide

Thanks for your interest in improving this guide! Contributions are welcome from everyone — whether you're fixing a typo or suggesting a new section.

## Ways to Contribute

- Fix typos or grammar errors
- Suggest improvements to existing sections
- Add new tips or resources
- Report broken links
- Share your own experience (via issue or PR)

## How to Suggest Changes

### Option 1: Open an Issue

If you have an idea but don't want to write code:

1. Go to the [Issues](https://github.com/Ankitjha9732/github-profile-guide/issues) tab
2. Click **New Issue**
3. Describe your suggestion clearly
4. Submit

### Option 2: Fork and Pull Request

If you want to make changes directly:

**Step 1: Fork the repository**

Click the **Fork** button at the top right of the repo page. This creates a copy under your GitHub account.

**Step 2: Clone your fork**

```bash
git clone https://github.com/YOUR_USERNAME/github-profile-guide.git
cd github-profile-guide
```

**Step 3: Create a new branch**

```bash
git checkout -b your-branch-name
```

Use a descriptive branch name like:
- `fix/typo-in-checklist`
- `add/typescript-section`
- `improve/project-template`

**Step 4: Make your changes**

Edit the files using your preferred editor.

**Step 5: Commit your changes**

```bash
git add .
git commit -m "Brief description of your change"
```

**Step 6: Push to your fork**

```bash
git push origin your-branch-name
```

**Step 7: Create a Pull Request**

1. Go to your fork on GitHub
2. Click **Compare & pull request**
3. Fill in a clear title and description
4. Submit the pull request

## Guidelines

- Keep changes focused — one improvement per PR
- Match the existing style and tone
- Don't add made-up personal experiences
- Test any code examples you add
- Be respectful and constructive

## Questions?

If you're unsure about anything, open an issue and ask. No contribution is too small.
