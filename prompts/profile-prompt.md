# GitHub Profile README — AI Prompt

Copy the prompt below and paste it into ChatGPT, Claude, Gemini, or any capable AI model. Fill in your own information where indicated.

---

## The Prompt

```
I want to create a professional GitHub profile README. Help me generate one based on the information I provide below. Use ONLY the information I give you — do not invent projects, skills, achievements, or experience that I do not mention.

Here is my information:

**Basic Information:**
- Full name: [YOUR NAME]
- Current role or title: [YOUR ROLE, e.g., "Student", "Frontend Developer", "Full-Stack Developer"]
- One-line introduction: [A SHORT SENTENCE ABOUT WHAT YOU DO]
- Location: [YOUR COUNTRY/CITY — optional]
- Education: [YOUR DEGREE, BRANCH, UNIVERSITY — optional]

**About Me:**
Write 2-3 sentences about:
- What you do
- What technologies you work with
- What you're interested in or working on
- What you're looking for (internships, roles, collaborations)

Example (do not copy — write your own):
"I am a frontend developer focused on building responsive, interactive web applications using React and modern CSS. I enjoy working on UI/UX design and turning ideas into real products. Currently open to frontend roles and collaborations."

**Tech Stack:**
List the technologies you actually use, organized by category:

Frontend: [e.g., HTML, CSS, JavaScript, React, Tailwind]
Backend: [e.g., Node.js, Express, MongoDB]
Tools: [e.g., Git, VSCode, Vercel, Postman]
Other: [e.g., Figma, Firebase, TypeScript]

**Projects (2-4 projects):**
For each project, provide:
- Project name: [PROJECT NAME]
- What it does: [1-2 SENTENCES DESCRIBING THE USER EXPERIENCE]
- Key features: [LIST 2-4 FEATURES]
- Tech stack: [TECHNOLOGIES USED]
- Live demo link: [URL — if available, otherwise write "none"]
- Repository link: [URL]

**Links:**
- GitHub: [YOUR GITHUB URL]
- LinkedIn: [YOUR LINKEDIN URL]
- Portfolio: [YOUR PORTFOLIO URL — if available]
- Twitter/X: [YOUR TWITTER URL — if available]
- Email: [YOUR EMAIL — if available]

**Output Requirements:**
1. Generate clean GitHub-compatible Markdown
2. Use a professional layout with clear sections
3. Use shields.io badges for links (Portfolio, LinkedIn, GitHub)
4. Use skillicons.dev icons for tech stack: https://skillicons.dev/icons?i=html,css,js,react
5. Keep the design clean — avoid excessive emojis or animations
6. Include these sections:
   - Introduction (name + role + one-liner)
   - About Me
   - Tech Stack (with icons)
   - Featured Projects (with descriptions and links)
   - Currently Learning (if I mentioned this)
   - Links/Contact
7. Do NOT invent any information I did not provide
8. If I am missing important information, ask me before generating
9. Make the profile easy to read and scan
10. Keep it under 200 lines of Markdown
```

---

## How to Use This Prompt

1. Click the "Copy" button on the code block above
2. Open ChatGPT, Claude, Gemini, or another AI model
3. Paste the prompt
4. Fill in YOUR information in the `[BRACKETS]`
5. Send the message
6. Copy the generated README
7. Paste it into your GitHub profile README
8. Review and customize as needed

---

## Tips

- **Be honest** — only list skills and projects you actually have
- **Be specific** — "React, Node.js, MongoDB" is better than "full-stack"
- **Show real projects** — even small projects count
- **Include live demos** — deployed projects are more convincing
- **Ask for revisions** — tell the AI to adjust tone, layout, or content
