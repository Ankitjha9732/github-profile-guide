# Improve Your Existing Profile — AI Prompt

Copy the prompt below and paste it into ChatGPT, Claude, Gemini, or any capable AI model. Paste your existing GitHub profile README in the indicated section.

---

## The Prompt

```
I want to improve my existing GitHub profile README. I will paste my current README below. Please review it and help me make it better.

**My Current GitHub Profile README:**

[PASTE YOUR EXISTING GITHUB PROFILE README HERE]

**My Context (optional — helps the AI give better feedback):**
- I am a [YOUR ROLE, e.g., "student", "junior developer", "frontend developer"]
- I have [X] years of experience / I am [beginner/intermediate/advanced]
- I am looking for [internships / jobs / collaborations / open source]
- My main technologies are: [LIST YOUR MAIN TECHS]

**Please do the following:**

1. **Evaluate my profile** on these criteria:
   - Clarity — Is it clear what I do and what I'm looking for?
   - Professional appearance — Does it look polished and organized?
   - Introduction — Is my intro clear and concise?
   - Tech stack — Is it well-presented with icons or categories?
   - Projects — Are projects described well with features and links?
   - Links — Do I have the right links (GitHub, LinkedIn, portfolio)?
   - Structure — Is the Markdown well-organized with clear sections?
   - Content balance — Is there too much or too little content?
   - Missing information — Is there anything useful I should add?
   - Beginner mistakes — Are there any common mistakes in my profile?

2. **Provide a list of problems found:**
   - List each issue clearly
   - Explain why it is a problem
   - Rate severity: High / Medium / Low

3. **Provide recommended improvements:**
   - Specific changes I should make
   - New sections I should add (if any)
   - Sections I should remove or simplify (if any)
   - Better wording suggestions (if applicable)

4. **Generate an improved version:**
   - Take my existing README and make the improvements
   - Do NOT invent new projects, skills, or achievements
   - Only improve what is already there
   - Keep my personal style and tone
   - Keep my actual experience and information intact

**Output Requirements:**
1. First, give me a summary (2-3 sentences)
2. Then, list problems found (numbered list)
3. Then, list recommended improvements (numbered list)
4. Then, provide the improved README in a code block
5. Do NOT invent information I did not provide
6. Only improve structure, wording, and presentation
```

---

## How to Use This Prompt

1. Click the "Copy" button on the code block above
2. Open ChatGPT, Claude, Gemini, or another AI model
3. Paste the prompt
4. Replace `[PASTE YOUR EXISTING GITHUB PROFILE README HERE]` with your actual README
5. Fill in the optional "My Context" section for better feedback
6. Send the message
7. Review the feedback and improved version
8. Apply the changes to your profile

---

## What to Expect

The AI will give you:

- **Summary** — overall assessment of your profile
- **Problems** — specific issues to fix
- **Recommendations** — actionable improvements
- **Improved README** — a revised version you can use

---

## Tips

- **Be honest in your context** — the AI can only help if it knows your level
- **Apply changes gradually** — don't change everything at once
- **Keep your voice** — the AI should improve your writing, not replace it
- **Check before publishing** — always review the AI output for accuracy
- **Run this periodically** — as you build new projects, update your profile
