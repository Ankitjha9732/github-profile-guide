# Project README — AI Prompt

Copy the prompt below and paste it into ChatGPT, Claude, Gemini, or any capable AI model. Fill in your own project information where indicated.

---

## The Prompt

```
I want to create a professional README for my GitHub project. Help me generate one based on the information I provide below. Use ONLY the information I give you — do not invent features, capabilities, or project details that I do not mention.

Here is my project information:

**Basic Information:**
- Project name: [PROJECT NAME]
- One-line description: [WHAT THE PROJECT DOES IN ONE SENTENCE]
- What problem it solves: [2-3 SENTENCES EXPLAINING THE PROBLEM AND YOUR SOLUTION]

**Features:**
List the key features of this project:
- [FEATURE 1]
- [FEATURE 2]
- [FEATURE 3]
- [FEATURE 4]

**Tech Stack:**
- Frontend: [TECHNOLOGIES]
- Backend: [TECHNOLOGIES — if applicable]
- Database: [TECHNOLOGIES — if applicable]
- Other tools: [TECHNOLOGIES]

**Setup:**
- How to install: [npm install, pip install, etc.]
- How to run: [npm start, python app.py, etc.]
- Environment variables needed: [LIST ANY ENV VARS OR WRITE "none"]

**Links:**
- Live demo: [URL — if available]
- Repository: [URL]

**Screenshots:**
- I have screenshots: [yes/no]
- Screenshot filenames: [e.g., screenshot1.png, screenshot2.png]

**Additional Information:**
- API endpoints: [LIST IF APPLICABLE, OTHERWISE WRITE "none"]
- Project structure: [LIST KEY FOLDERS IF USEFUL, OTHERWISE WRITE "none"]
- Future improvements: [LIST IF YOU HAVE PLANNED IMPROVEMENTS, OTHERWISE WRITE "none"]

**Output Requirements:**
1. Generate clean GitHub-compatible Markdown
2. Include these sections:
   - Project title and description
   - Features
   - Tech stack
   - Live demo link (if provided)
   - Screenshots (reference the filenames I provided)
   - Getting started (installation and setup)
   - Environment variables (if any)
   - Usage
   - API endpoints (if applicable)
   - Project structure (if useful)
   - Future improvements (if any)
   - Contributing guidelines (short)
   - License (use MIT unless I specify otherwise)
3. Do NOT invent any information I did not provide
4. If I am missing important information, ask me before generating
5. Keep the README clean and professional
6. Use shields.io badges for the live demo link
7. Reference screenshots using relative paths: ![Screenshot](screenshots/screenshot1.png)
```

---

## How to Use This Prompt

1. Click the "Copy" button on the code block above
2. Open ChatGPT, Claude, Gemini, or another AI model
3. Paste the prompt
4. Fill in YOUR project information in the `[BRACKETS]`
5. Send the message
6. Copy the generated README
7. Paste it into your project's `README.md` file
8. Review and customize as needed

---

## Tips

- **Describe what it does, not just the tech** — "QR restaurant ordering with real-time updates" is better than "A Node.js app"
- **Include screenshots** — visual proof is powerful
- **Add a live demo** — even a simple deployment shows you can ship
- **List environment variables** — so others can actually run your project
- **Keep it scannable** — use headers, bullet points, and short paragraphs
