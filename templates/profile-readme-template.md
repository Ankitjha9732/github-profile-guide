## Tips

- **Be honest** — only include real skills and projects
- **Be specific** — "React, Node.js, MongoDB" is better than "full-stack"
- **Include live demos** — deployed projects are more convincing
- **Keep it scannable** — use headers, bullet points, and short paragraphs
- **Update regularly** — add new projects as you build them
