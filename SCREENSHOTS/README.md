# Screenshots

This folder contains screenshots used in the guide.

## Images

| Filename | Description | Where It's Used |
|---|---|---|
| `profile.png` | Screenshot of your complete GitHub profile page | Main README — "See My Profile as an Example" section |
| `repos.png` | Screenshot of organized repositories | Main README — "Step-by-Step" section |
| `techstack.png` | Screenshot of tech stack section | Main README — "Step-by-Step" section |

## How to Add More Screenshots

1. Take a screenshot of the relevant page
2. Save it with a descriptive filename
3. Place it in this `SCREENSHOTS/` folder
4. Reference it in the main README

## Image Tips

- Use PNG format for clarity
- Crop to show only relevant content
- Max width: 1200px (GitHub renders well at this size)
- Keep file size reasonable (under 500KB each)

## Reference in Markdown

To use a screenshot in the main README:

```markdown
![Alt text](SCREENSHOTS/filename.png)
```

Or with HTML for sizing:

```html
<img src="SCREENSHOTS/filename.png" alt="Description" width="800" />
```
