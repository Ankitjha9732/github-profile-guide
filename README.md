## ⚡ Step-by-Step

### Step 1 — Prepare Your Information

Have these ready: name, role, skills, 2–3 projects, education/experience (if relevant), GitHub, LinkedIn, and portfolio links.

### Step 2 — Copy the AI Prompt

**[🚀 Create My Profile with AI →](./prompts/profile-prompt.md)**

### Step 3 — Open Your AI

Paste the prompt into ChatGPT, Claude, Gemini, or another AI assistant.

### Step 4 — Give AI Your Information

Replace the `[PLACEHOLDERS]` in the prompt with your real information. Never let AI invent skills, projects, or achievements.

### Step 5 — Generate & Review

Check the output for: incorrect information, fake skills, fake projects, and broken links. Make changes as needed.

### Step 6 — Create Your Profile README

1. Go to [github.com/new](https://github.com/new)
2. Name the repository exactly your GitHub username
3. Add `README.md`
4. Paste your generated README
5. Commit

### Step 7 — Improve Your Profile

- Pin your best repositories
- Add descriptions to all repos
- Create project READMEs
- Add screenshots and demo links

### Step 8 — Done 🎉
