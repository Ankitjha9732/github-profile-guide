## Step-by-Step Guide

### Step 1: Check the Example

Look at my GitHub profile to see what a finished profile looks like.

**My GitHub Profile:** [https://github.com/Ankitjha9732](https://github.com/Ankitjha9732)

**My Profile README Source:** [github.com/Ankitjha9732/Ankitjha9732](https://github.com/Ankitjha9732/Ankitjha9732)

> Use this as inspiration — not something to copy exactly. Your profile should reflect your own skills and projects.

---

### Step 2: Prepare Your Information

Before using the AI prompts, gather this information:

- Your name and role
- Your tech stack (what technologies you actually use)
- Your projects (2-4 projects with descriptions)
- Your links (GitHub, LinkedIn, portfolio)
- Your education (optional)

**Be honest** — only include real skills and projects. The AI will not invent anything for you.

---

### Step 3: Copy the AI Prompt

Choose the prompt you need:

| What You Need | Prompt |
|---|---|
| Create a new profile README | [🤖 Profile AI Prompt](./prompts/profile-prompt.md) |
| Create a project README | [🤖 Project README Prompt](./prompts/project-readme-prompt.md) |
| Improve an existing profile | [🤖 Improve Profile Prompt](./prompts/improve-profile-prompt.md) |

---

### Step 4: Give Your Information to AI

1. Open the prompt file
2. Copy the prompt
3. Open ChatGPT, Claude, Gemini, or another AI model
4. Paste the prompt
5. Fill in YOUR information in the `[BRACKETS]`
6. Send the message

---

### Step 5: Generate Your README

The AI will generate:

- A profile README (from the profile prompt)
- A project README (from the project prompt)
- Feedback and an improved version (from the improve prompt)

Copy the generated output.

---

### Step 6: Review and Customize

**Never use AI output without reviewing it first.**

Check for:
- Correct information (name, links, projects)
- No invented skills or projects
- Clean formatting
- Your personal style and tone

Make changes as needed. This is YOUR profile.

---

### Step 7: Add It to GitHub

**To create your profile README:**

1. Go to [github.com/new](https://github.com/new)
2. Name the repository exactly your username (e.g., `your-username`)
3. Check "Add a README file"
4. Create the repository
5. Paste your generated README into the `README.md` file
6. Commit and push

The README will now appear on your GitHub profile page.

**To add a project README:**

1. Open one of your project repositories
2. Edit or create the `README.md` file
3. Paste your generated project README
4. Commit and push

---

### Step 8: Improve Your Repositories

After your profile is live, continue improving:

- Pin your best 6 repositories
- Add descriptions and topics to all repos
- Deploy projects and add live demo links
- Add screenshots to project READMEs
- Clean up old or empty repositories

Use the [Improve Profile Prompt](./prompts/improve-profile-prompt.md) periodically to get feedback.

## GitHub Profile Checklist

Use this before publishing your profile:

- [ ] Profile README created (repo with your username)
- [ ] Clear introduction (name, role, what you do)
- [ ] Tech stack shown (with icons or categories)
- [ ] 2-3 projects with descriptions
- [ ] Live demo links (where available)
- [ ] Repository links for each project
- [ ] LinkedIn or portfolio link
- [ ] Pinned best 6 repositories
- [ ] Repos have descriptions and topics
- [ ] Project READMEs for each repo
- [ ] No fake claims or invented skills
- [ ] No secrets or API keys exposed
- [ ] Mobile-friendly (check on your phone)
- [ ] Proofread for typos

---

## Common Mistakes

| Mistake | Why It's a Problem |
|---|---|
| Leaving profile README empty | Wasted first impression |
| Listing technologies without context | Doesn't show how you use them |
| No project descriptions | Visitors don't know what you built |
| No live demos | Harder to verify your work |
| Exaggerating skills | Sets wrong expectations |
| Old, broken repos visible | Looks unfinished |
| No contact links | Missed connections |
| Using AI output without review | May contain incorrect information |
